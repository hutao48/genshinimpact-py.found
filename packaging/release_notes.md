## 原神乐器演奏检测器 1.1.3（Windows）

**本次仅更新 Windows 端，新增全透明常驻前台悬浮窗，并把 BPM 图默认改为折线。Android 端保持 1.1.1，不发布新 APK。**

### 新增：常驻前台悬浮窗

- 顶栏新增「悬浮窗」按钮，启动时默认显示；可随时隐藏/重新打开。
- **全透明背景、左右布局**：左侧完整琴键栏；右侧上方当前按键 / 和弦 / 调性 / BPM，右侧下方 BPM 实时折线。
- 悬浮窗内可直接切换检测乐器；与主窗口乐器同步。
- 始终置顶，可拖动标题栏移动、右下角缩放、× 隐藏。
- 悠可琴保留 7 个和弦键 + 2 排旋律键；晚风圆号保留 2 排；其余乐器 3 排 × 7 列。

### Windows / 悬浮窗：BPM 折线

- 主窗口和悬浮窗的 BPM 图默认使用折线。
- 图表右上角「折线 / 柱状」可随时切回直方图；主窗口保留时间范围、当前/平均/最低/最高与悬停读数。

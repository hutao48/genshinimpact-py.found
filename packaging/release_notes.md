## 原神乐器演奏检测器 1.1.0

### 下载

| 文件 | 说明 |
|---|---|
| `GenshinInstrumentDetector-1.1.0-win64-setup.exe` | **Windows 安装程序**：安装到当前用户目录（无需管理员），创建开始菜单/桌面快捷方式，可在“设置 → 应用”中卸载；覆盖安装即可从旧版升级 |
| `GenshinInstrumentDetector-1.1.0-win64-portable.exe` | **Windows 免安装版**：单文件，双击即可运行（首次启动需 2–5 秒解压） |
| `GenshinInstrumentDetector-1.1.0-android.apk` | **Android 安装包**：Android 7.0 及以上 |
| `SHA256SUMS.txt` | 以上文件的 SHA-256 校验和 |

> Windows exe 未做代码签名，SmartScreen 可能提示“未知发布者”，点击“更多信息 → 仍要运行”即可。
> Android 从 1.1.0 起使用**固定发布签名**；从旧版（调试签名）升级需要先卸载一次，之后所有版本可直接覆盖安装。

### 新增：游戏内样式琴键栏

- 琴键栏改为与游戏内一致的圆形键面：奶油色圆盘、`do re mi fa so la ti` 唱名、音级符号和行首的高音/中音/低音谱号。
- 6 种乐器各有配色：风物之诗琴（青绿）、镜花之琴（棕金）、跃律琴（青色）、谐律键琴（琥珀）、晚风圆号（橙金）、悠可琴（蓝色和弦键 + 两排音高键）。
- 切换顶部“乐器”时，琴键数量、行数、谱号、和弦键和配色同步切换；发音时按该乐器主色高亮，并保留小号电脑键位字母（Q/W/E…）方便对照。
- 背景加入五线谱线和微弱星点，深色/浅色主题各有一套配色。

### 新增：自动更新（Windows）

- 设置中新增“发现新版本后自动下载并安装”，可自行选择开启或关闭。
- 开启后：发现新版本 → 下载对应 `win64-setup.exe` → 用 GitHub Releases 资产提供的 SHA-256 校验 → 校验通过后静默安装并重启应用。
- 未开启或校验失败时只提示并给出下载页面，不执行任何文件。
- 下载过程显示进度，可取消；仅接受本仓库 GitHub Releases 的 HTTPS 链接，并限制安装包大小。
- 自动更新运行的是标准安装程序；免安装版如果希望继续保持免安装，请关闭自动更新，改为从下载页获取新的 portable 文件。

### 新增：Android 内置更新与固定签名

- Android 增加“检查更新”按钮：查询 GitHub Releases，下载新版 APK，校验 SHA-256 后打开系统安装器；安装仍需用户在系统界面确认。
- Android 1.1.0 起使用固定的发布密钥签名，后续版本使用同一签名，可直接覆盖安装升级。
- 由于历史版本使用调试签名，首次从 1.0.3/更早版本升级到 1.1.0 时，系统可能提示签名不一致，需要卸载旧版后安装一次。

### 其他

- 版本统一为 1.1.0（Windows / Android）。
- 设置窗口的语言、主题、更新选项保持不变；更新检查仍默认关闭，自动更新需显式开启。
- 仓库保持只保留运行代码与打包资源；测试/评测源码和录音仍不在仓库中。

### 安全说明

- 自动更新只从 `https://api.github.com/repos/hutao48/genshinimpact-py.found/releases/latest` 读取元数据，从该 Release 的 GitHub 下载地址获取安装包。
- 安装包必须通过 SHA-256 校验和 PE 头检查后才会执行；失败会取消安装。
- Android APK 必须通过 SHA-256 校验后才交给系统安装器。
- 更新检查/自动更新均可在设置中关闭。

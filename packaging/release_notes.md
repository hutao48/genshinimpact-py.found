## 原神乐器演奏检测器 1.1.5（Windows）

**本次仅更新 Windows 端；Android 保持 1.1.1。修复导出，重做悬浮窗信息布局。**

### 悬浮窗

- 去掉 BPM / 调性 / 和弦 / 当前按键四块文字指标。
- **右上**：BPM 走向图（修复之前悬浮窗中 BPM 曲线不刷新的问题）。
- **右下**：MIDI 编辑器风格的按键时间线：
  - 横轴时间、纵轴键位（含琴键字母和音名/和弦名）。
  - 横条准确显示每个键从按下到抬起的时间。
  - 同时按下的键会在相邻轨道上并排显示。
  - 悠可琴的和弦键与旋律键、晚风圆号两排均完整显示。
- 悬浮窗默认关闭；可在顶栏「悬浮窗」按钮或设置中开启。
- 保留悬浮窗内切换检测乐器、拖动标题栏、右下角缩放、始终置顶。

### 导出修复

- 导出改为非原生保存对话框，修复部分 Windows 环境下保存对话框不出现/无法保存的问题。
- 统一写入三个 CSV：音符时长、BPM、边界值排查；即使某类记录为空也会生成表头。
- 增加导出完成提示，可直接打开所在文件夹；错误会显示具体原因。

### BPM 图

- 主窗口和悬浮窗均默认折线；保留「折线 / 柱状」手动切换。
- 悬浮窗 BPM 曲线现在会随采样实时刷新。
